# Beginner to Senior in Full-Stack

Plataforma de estudos e portfólio pessoal para dominar **Back-End** e **Full-Stack**, do zero ao nível sênior.

## 🎯 Objetivo

Uma trilha única, estruturada e verificada para aprender:

- ☕ **Java** — do Hello World a microsserviços
- 🗄️ **SQL** — do SELECT a performance
- 🌱 **Spring Boot** — do @RestController a segurança avançada
- 🐳 **Docker** — do docker run a orquestração
- ☁️ **AWS** — do Free Tier a arquitetura resiliente
- 🔧 **Back-end Geral** — Git, HTTP, Linux, system design
- 🎨 **Front-End** — HTML + CSS + JS para interface profissional

## 📐 Estrutura de cada trilha

Toda trilha segue o mesmo padrão de 5 níveis:

| Nível | Foco |
| :--- | :--- |
| 🟢 1 | Fundamentos |
| 🟡 2 | Aprofundamento |
| 🟠 3 | Aplicação real |
| 🔴 4 | Sênior |
| 🟣 5 | **Exame de Certificado** |

### 🟣 Nível 5 — Exame de Certificado

Cada trilha tem **5 provas finais**, sendo a **Prova 5** o exame de certificação:

- O aluno abre o desafio com **apenas a cheat sheet code ao lado**
- Sem tutorial, sem busca, sem dica
- Passou = **selo da trilha** (badge no GitHub)

Ao completar todas as 7 trilhas: **🏆 Beginner to Senior in Full-Stack — Certified**

## 📂 Projeto prático

O principal projeto de prática é o **Streak Tracker** — sistema de tracking de estudos.

Construído em **Java + Spring Boot + SQL + Docker + AWS**, evoluindo junto com a trilha.
